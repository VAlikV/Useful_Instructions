# Основные команды для Docker

Образ (image) — шаблон с приложением и его зависимостями. Контейнер — экземпляр, созданный из образа. Команда `docker run` создаёт новый контейнер, а `docker start` запускает уже существующий.

В командах ниже заменяйте значения в `<...>` своими, без угловых скобок. Вместо `<container_id>` можно использовать ID или имя контейнера. Docker должен быть установлен и запущен; если для доступа к нему нужны права администратора, добавляйте `sudo` перед командами.

## Просмотр образов и контейнеров

```bash
docker image list  # Локальные образы
docker ps          # Запущенные контейнеры
docker ps -a       # Все контейнеры, включая остановленные
```

## Создание контейнера и вход в него

Создать контейнер из образа и запустить его в фоновом режиме:

```bash
docker run -it -d --name <container_name> <image_name>:<tag>
```

Параметр `--name` задаёт имя контейнера, `-d` запускает его в фоне, а `-it` оставляет стандартный ввод открытым и выделяет псевдотерминал. Если образа нет локально, Docker попробует скачать его из реестра. Контейнер работает, пока выполняется его основной процесс.

Открыть оболочку в работающем контейнере:

```bash
docker exec -it <container_id> bash
```

Если в образе нет `bash`, попробуйте `sh`. Команда `exit` закрывает эту оболочку, не останавливая основной процесс контейнера.

## Управление контейнером

```bash
docker stop <container_id>     # Остановить
docker start <container_id>    # Запустить остановленный контейнер
docker restart <container_id>  # Перезапустить
```

## Копирование файлов

Скопировать файл из контейнера на хост:

```bash
docker cp <container_id>:/path/in/container/file /path/on/host/
```

Для копирования с хоста в контейнер поменяйте источник и назначение местами:

```bash
docker cp /path/on/host/file <container_id>:/path/in/container/
```

## Удаление

Сначала остановите контейнер, затем удалите его. При удалении теряются данные в записываемом слое контейнера; данные в томах (volumes) и подключённых каталогах хоста сохраняются.

```bash
docker stop <container_id>
docker rm <container_id>
```

Удалить локальный образ можно после удаления контейнеров, которые на него ссылаются:

```bash
docker rmi <image_id>
```
