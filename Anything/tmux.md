# Шпаргалка по tmux

`tmux` — терминальный мультиплексор: несколько терминалов, окна и панели внутри одной сессии. Процессы продолжают работать после отключения от SSH, если сессия tmux остаётся запущенной.

> **Префикс:** большинство сочетаний начинаются с `Ctrl+B`. Нажми `Ctrl+B`, отпусти, затем следующую клавишу.

## 1. Управление сессиями

| Команда | Действие |
|---|---|
| `tmux` | Создать новую сессию |
| `tmux new -s name` | Создать именованную сессию |
| `tmux ls` | Показать сессии |
| `tmux attach -t name` | Подключиться к сессии |
| `tmux a` | Подключиться к последней сессии |
| `tmux kill-session -t name` | Завершить сессию |
| `tmux kill-server` | Завершить все сессии |
| `tmux rename-session -t old new` | Переименовать сессию |

### Горячие клавиши для сессий

| Сочетание | Действие |
|---|---|
| `Ctrl+B` → `d` | Отсоединиться, не останавливая процессы |
| `Ctrl+B` → `s` | Список сессий и переключение |
| `Ctrl+B` → `$` | Переименовать сессию |

## 2. Окна (windows)

| Сочетание | Действие |
|---|---|
| `Ctrl+B` → `c` | Создать окно |
| `Ctrl+B` → `n` | Следующее окно |
| `Ctrl+B` → `p` | Предыдущее окно |
| `Ctrl+B` → `0`–`9` | Перейти к окну по номеру |
| `Ctrl+B` → `w` | Список окон |
| `Ctrl+B` → `,` | Переименовать окно |
| `Ctrl+B` → `&` | Закрыть окно с подтверждением |

## 3. Панели (panes)

| Сочетание | Действие |
|---|---|
| `Ctrl+B` → `%` | Разделить окно вертикальной границей (слева/справа) |
| `Ctrl+B` → `"` | Разделить окно горизонтальной границей (сверху/снизу) |
| `Ctrl+B` → `←` / `↑` / `→` / `↓` | Перейти к соседней панели |
| `Ctrl+B` → `o` | Перейти к следующей панели |
| `Ctrl+B` → `;` | Вернуться к предыдущей активной панели |
| `Ctrl+B` → `z` | Развернуть панель / восстановить |
| `Ctrl+B` → `x` | Закрыть панель с подтверждением |
| `Ctrl+B` → `Space` | Сменить раскладку панелей |
| `Ctrl+B` → `Ctrl+стрелка` | Изменить размер панели |
| `Ctrl+B` → `!` | Перенести панель в новое окно |

## 4. Прокрутка и копирование

| Сочетание | Действие |
|---|---|
| `Ctrl+B` → `[` | Перейти в режим копирования/прокрутки |
| `↑` / `↓`, `PgUp` / `PgDn` | Прокрутка истории |
| `Space` | Начать выделение (если включён `mode-keys vi`) |
| `Enter` | Скопировать выделенное |
| `Ctrl+B` → `]` | Вставить из буфера tmux |
| `q` | Выйти из режима копирования |

## 5. Полезный `~/.tmux.conf`

```tmux
# Управление мышью
set -g mouse on

# Нумерация окон и панелей с единицы
set -g base-index 1
setw -g pane-base-index 1

# Размер истории
set -g history-limit 50000

# Клавиши vi в режиме копирования
setw -g mode-keys vi

# Ctrl+B, затем r — перезагрузить конфигурацию
bind r source-file ~/.tmux.conf \; display-message "Config reloaded"
```

Применить настройки без перезапуска:

```bash
tmux source-file ~/.tmux.conf
```

## 6. Типичный сценарий

```bash
# Создать сессию
tmux new -s project

# Запустить долгую задачу
python train.py
```

Отсоединиться: `Ctrl+B` → `d`.

```bash
# Посмотреть сессии
tmux ls

# Вернуться в нужную
tmux attach -t project
```

**Важно:** `Ctrl+B` → `d` отсоединяет клиента, не завершая сессию. `exit` закрывает текущую оболочку; если это последняя панель, сессия завершится.

## 7. Дополнительные сочетания

| Сочетание | Действие |
|---|---|
| `Ctrl+B` → `?` | Справка по сочетаниям |
| `Ctrl+B` → `:` | Командная строка tmux |
| `Ctrl+B` → `t` | Часы |
